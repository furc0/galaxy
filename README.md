## Установка на Android

1. Нажмите кнопку **СКАЧАТЬ APK** выше.
2. Дождитесь загрузки файла `Prizma.apk`.
3. Откройте файл на телефоне.
4. Если Android запросит разрешение, разрешите установку приложений из используемого источника.

## Обновления

Новая Android-сборка автоматически публикуется в разделе [Releases](https://github.com/furc0/galaxy/releases) после успешной сборки GitHub Actions. Кнопка выше всегда ведёт к последнему опубликованному APK.

> Примечание: это APK для прямой установки, не версия из Google Play.
